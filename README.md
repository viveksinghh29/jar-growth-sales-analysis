# Jar Growth Intern Assignment — Sales Data Analysis

## Project Overview
This project analyzes sales, profit, product categories, subcategories, monthly trends, geographic performance, and Furniture sales-target achievement using Python.

## Business Questions
1. Which categories generate the most revenue versus profit?
2. Which subcategories have high sales but weak or negative profitability?
3. Which months show the strongest growth or biggest decline?
4. Which locations contribute most to profit rather than merely sales?
5. Did Furniture meet its monthly sales targets, and in which months did it fall short?
6. What practical actions should the business take based on the findings?

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Exploratory Data Analysis (EDA)
- Data Cleaning and Visualization

## Analysis Workflow
1. Load and inspect the datasets.
2. Clean and validate the data.
3. Merge order and sales-detail datasets.
4. Calculate overall business KPIs.
5. Analyze category and subcategory profitability.
6. Evaluate monthly sales growth and geographic performance.
7. Compare Furniture sales with monthly targets.
8. Summarize findings and business recommendations.

## How to Run
1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn jupyter`

4. Open the notebook in VS Code or Jupyter Notebook.
5. Run the cells in order.
